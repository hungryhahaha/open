## 브리프 코치 (`brief-coach/`)

임원 1:1 구두 보고를 휴대폰에서 소리 내어 연습하면, 끝까지 다 들은 뒤 구조·억양·강세·속도를 짚어 주고
고쳐서 다시 말하면 지난번과 비교해 주는 웹앱입니다. 억양 분석은 기기 안에서 하고, OpenAI API 키를 넣으면
받아 적기·AI 코칭·모범 낭독을 씁니다(키는 각자 휴대폰 브라우저에만 저장).

- 페이지: https://hungryhahaha.github.io/open/brief-coach/
- 설치·사용법: [`brief-coach/README.md`](brief-coach/README.md)
